# fts-15-stats-converter
Conversor web de estadísticas de jugadores desde FC27 (SoFIFA), eFootball 2027, PES 2021 y Football Manager hacia First Touch Soccer 15 (FTS15). Incluye escalado realista o equivalente, gestión por carpetas/equipos, exportación masiva en .ZIP y bookmarklets de extracción automática.
