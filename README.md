# ⚽ FTS15 Stats Converter — Kits PLS Argentina Modding Tool

Herramienta web gratuita diseñada para modders de **First Touch Soccer 15 (FTS15)** que permite convertir atributos de jugadores desde bases de datos modernas hacia el formato exacto de FTS15 (`players.dat` / `.txt`).

### 🌐 Usar la herramienta online
👉 **[Abrir FTS15 Stats Converter](https://dantebatista52.github.io/fts-15-stats-converter/index.html)**  
📖 **[Ver Guía de Uso y Bookmarklets](https://dantebatista52.github.io/fts-15-stats-converter/guia.html)**

---

### ✨ Características principales

* **Múltiples juegos de origen:** Soporte para **EA FC / FC27** (SoFIFA), **eFootball 2027** (eFootballHUB), **PES 2021** (PES Master) y **Football Manager** (FMInside).
* **Dos modos de conversión:**
  * *Simulación Realista (Puro):* Traduce los atributos respetando las proporciones originales sin inflación.
  * *Media Equivalente (FTS15 +):* Compensa los pesos internos del motor de FTS15 para que el **Global** coincida con la carta original.
* **Extracción automática en 1 clic (Bookmarklets):** Scripts incluidos en la guía para descargar fichas `.json` directamente desde SoFIFA, FMInside, eFootballHUB y PES Master (compatible con PC y navegadores móviles).
* **Organización por carpetas y equipos:** Crea jerarquías (ej. `Argentina/Primera/Club`) y descarga planteles completos en un solo archivo **`.ZIP`** o fichas individuales en **`.TXT`**.

---

### 💾 Privacidad y Almacenamiento
La aplicación funciona 100% en el navegador. Todos los jugadores y carpetas que guardes se almacenan de forma privada en el **`localStorage`** de tu propio dispositivo. 
> **Recomendación:** Usa el botón **"Respaldar Base"** periódicamente para guardar una copia `.json` de tu trabajo antes de limpiar el historial o caché del navegador.
